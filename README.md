# GLASS BENTO 天氣穿搭網頁

公開靜態預覽：https://abao0916335391-alt.github.io/weather-outfit-preview/

以 GitHub Pages 的 main 分支根目錄發布。此公開儲存庫包含靜態網頁、字體與第三方套件授權檔。

## 預覽功能與限制

可切換城市、亮暗主題，以及查看依 Asia/Shanghai 日期計算的五行幸運色。

本預覽未部署天氣代理，也不需要 MET_CONTACT。即時天氣、穿搭建議與 24 小時曲線會顯示空值或提示，不使用假資料。定位僅在按下定位按鈕後請求權限；即使取得定位，靜態版仍不會取得天氣。

## 驗證方式

開啟預覽網址，確認頁面與字體載入、城市切換、亮暗主題切換及重新整理後主題保留，並查看今日幸運色。手機寬度下確認版面沒有橫向溢出。
